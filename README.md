## Project Overview

As part of my **Data Science and Machine Learning portfolio**, I completed this project to strengthen my understanding of **Linear Regression** and the end-to-end machine learning workflow.

The project was inspired by a tutorial from Alejandro AO's YouTube channel:

🔗 https://www.youtube.com/watch?v=O2Cw82YR5Bo

---

## Business Problem

For this training scenario, we assume an e-commerce company is trying to determine whether it should invest more resources in improving its **mobile app experience** or its **website**.

Using customer behavior data, a **Linear Regression model** is built to identify which factors have the strongest relationship with customer spending. The insights generated from the model can help guide business decisions and resource allocation.

> **Note:** This is an educational project. The data is not based on real customers and is used solely for learning and practice purposes.

---

## Dataset

The dataset used in this project is publicly available on Kaggle:

🔗 **Ecommerce Customer Device Usage Dataset**  
https://www.kaggle.com/iyadavvaibhav/ecommerce-customer-device-usage

### Features Included

- **Avg. Session Length** – Average duration of in-store style consultation sessions.
- **Time on App** – Average time spent using the mobile application.
- **Time on Website** – Average time spent browsing the website.
- **Length of Membership** – Number of years the customer has been a member.

All customer information in the dataset is fictional and intended for educational purposes only.
